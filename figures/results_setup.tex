All results below use a single training configuration, held fixed across every
geometry and resolution. The solution is represented by the network of
Eq.~\eqref{eq:network}: two hidden layers of $100$ units with $\tanh$ activations and a
linear scalar output, $10{,}601$ parameters, initialised from a fixed random seed.
Training uses AdamW with a cosine-annealed learning rate from $r_0 = 10^{-3}$, no weight
decay, and $\varepsilon = 10^{-16}$ (Section~\ref{sec:eps}) for $10{,}000$ epochs. The
batch comprises every grid point in $\Omega^{-}$, so each epoch performs exactly one
optimizer update at every resolution. All runs were performed on a single GPU.

Errors are evaluated on a $128^{3}$ grid independent of the training grid and are
restricted to $\Omega^{-}$; the exterior is excluded, since the equations posed there
involve only the untrained exterior network. The two grids are non-nesting, so
essentially every reported error is measured at coordinates at which no equation was
imposed during training. The metrics are converged with respect to the evaluation
resolution: subsampling to $32^{3}$ changes the RMSE by less than $0.21\%$ and the
$L^{\infty}$ error by less than $2.0\%$.

For each accuracy metric we report the order of convergence $p$, computed by doubling
the number of grid points in every dimension and comparing successive errors,
\begin{equation}
  \frac{\mathrm{err}(2h)}{\mathrm{err}(h)} = 2^{p}
  \;\Rightarrow\;
  p = \log_{2}\!\left(\frac{\mathrm{err}(2h)}{\mathrm{err}(h)}\right).
  \label{eq:order}
\end{equation}
